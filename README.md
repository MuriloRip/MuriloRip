## Sobre

Tenho interesse em entender como sistemas funcionam por dentro e em criar ferramentas úteis para infraestrutura. No momento, concentro meus projetos em duas frentes: um sistema operacional experimental e uma aplicação de monitoramento de rede.

## Projetos em destaque

### [FonsecaOS](https://github.com/MuriloRip/fonseca-os)
Sistema operacional acadêmico e experimental, desenvolvido para explorar kernel, memória, processos, armazenamento, rede e interface gráfica. O kernel é escrito principalmente em **C**, com **Assembly** em partes de baixo nível; o projeto pode ser compilado e testado no **QEMU**.

> Projeto experimental e em evolução — não é uma distribuição pronta para uso geral.

### [CityPulse NOC](https://github.com/MuriloRip/citypulse-noc)
Painel de monitoramento e inventário de infraestrutura para redes autorizadas. A aplicação acompanha disponibilidade, incidentes e dependências de ativos, com sondagens e descoberta manual sujeita à revisão do operador.

**Tecnologias do projeto:** C#, ASP.NET Core (.NET 8), Entity Framework Core e SQLite.
